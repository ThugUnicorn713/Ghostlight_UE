
Ghostlight's build is made to run on Windows OS, Mac OS, and Linux OS!


How to Play Ghostlight

-turn on HTC VIVE VR headset 
-go into Build/Windows/....
-double click Ghostlight_UE


The Unreal Engine project is also enclosed in the Ghostlight_UE main folder in the case of wanting 
to see any logic or seeing the map while it is not dark. 
The files needed to open the project are the config and content folder which is enclosed in the Ghostlight_UE main folder.
You must download Unreal Engine 5.6 to open the project.
